# Анализатор системных логов БПЛА (Geoscan)

Скрипт на Python для автоматического анализа полётных логов и выявления аварийных ситуаций, ошибок и критических предупреждений.

## Что делает скрипт
* Сканирует лог-файл (`log.txt`) и находит строки с тегами `[CRITICAL]`, `[WARNING]` и `[ERROR]`.
* Парсит строку, разделяя её на метку времени и текст ошибки.
* Валидирует формат времени (длина строки времени должна быть не менее 7 символов), сообщая о некорректных записях.
* Безопасно обрабатывает повреждённые строки с помощью блока `except IndexError`.
* Формирует и выводит в консоль аккуратный итоговый отчёт обо всех авариях и предупреждениях.

## Как запустить
1. Положите файл с логами под именем `log.txt` в папку со скриптом.
2. Запустите скрипт через терминал:
   ```bash
   python log_analyzer.py
   ```
